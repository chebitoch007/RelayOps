# RelayOps brand assets

Logo = the site's own typography. "Relay" in Instrument Serif (ink), "Ops" in Instrument Serif Italic (accent),
and one signal node sitting in the counter of the R. Glyphs are outlined, so no font is needed to render them.

| File | Use |
| --- | --- |
| relayops-logo.svg | Primary, on paper/light backgrounds |
| relayops-logo-on-dark.svg | On `--night` / dark backgrounds |
| relayops-logo-mono.svg | One-colour contexts (print, stamps, fax) |
| relayops-mark.svg / -on-dark.svg | Standalone R + node, transparent |
| relayops-app-icon.svg / -paper.svg | Square tiles; PNG/ICO exports are generated from these |

Colours: ink #16140f, signal #e5531a, signal-ink #b23a0c (text), paper #f3eee4, night #12110d, signal-night #ff7a4d.
Clear space: the height of the "e" on every side. Minimum size: 24px high (wordmark), 16px (app icon).
Geometry for code lives in `lib/logo.ts`; Figma file: "RelayOps Redesign: Design System", page "Logo".
